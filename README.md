# BahaaStockJournal

**BahaaStockJournal** is a full-stack trading journal designed for active traders who want to track and improve their performance over time. Built with the MERN stack, it provides a structured and intuitive way to log trades, analyze daily/weekly/monthly stats, and stay accountable.


## ✨ Features

- 📆 **Calendar-based journaling**  
  Visualize all trades by day, week, or month in a clean calendar UI.

- 📈 **P&L Tracking**  
  Auto-calculate profit/loss across different time frames with summaries.

- 🔐 **Auth System (JWT-based)**  
  Register and log in securely. Includes admin/user roles.

- 🛠️ **Trade Entry Forms**  
  Easy and clean forms to enter trades with strategy, notes, RR, and more.

- 📊 **Charts & Stats** *(coming soon)*  
  Track win rate, equity curve, and tag-based filtering.

## ⚙️ Tech Stack

- **Frontend:** React + Vite + TypeScript + Tailwind CSS 
- **Backend:** Node.js + Express + TypeScript 
- **Database:** MongoDB  
- **Authentication:** JWT + Cookies



## 🧩 Key External Libraries & Components

Here are some of the main UI and utility libraries used in this project:

- **Flowbite React** – for ready-made Tailwind-based UI components like modals, tables, and tabs.  
- **PrimeReact** – used in the admin dashboard for DataTables and form controls.  
- **Recharts** – renders beautiful and customizable charts.  
- **TradingView Widget** – integrated for visualizing stock prices and patterns directly inside the app.



## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/bahaaabbas/BahaaStockJournal.git
```

### 2. Setup frontend (React)

```bash
cd client
npm install
npm run dev
```

### 3. Setup backend (Node.js + Express)

```bash
cd server
npm install
npm run dev
```

### 4. Environment variables (in `server/.env`)

```
MONGO_URI=your_mongo_connection_string
JWT_SECRET=your_jwt_secret
```
